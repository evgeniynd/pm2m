# pm2m для Android

Отдельное нативное приложение **pm2m**, разработчик **Prizm.Group**. Веб-проект в родительской папке не изменяется. Android подключается напрямую к Linux по SSH; серверная панель Node.js и Telegram не используются.

## Возможности

- Несколько SSH-подключений, пароль или приватный PEM/OpenSSH-ключ и passphrase.
- Проверка и закрепление SHA256 отпечатка до передачи пароля. Смена ключа сервера блокирует соединение.
- Список PM2, CPU/RAM, рестарты и время работы; незаметное обновление раз в 5 секунд на открытом экране без блокировки кнопок.
- Start/Stop/Restart/Reload/Delete с подтверждением и проверкой идентичности процесса; `pm2 save`.
- Отдельные stdout/stderr: последние 200 строк, ограничение 128 КиБ. Открытие на последней строке, обновление каждые 10 секунд без очистки текста. Если читать выше, позиция сохраняется.
- Создание приложения с выбором установленной Node.js (PATH/nvm/n/fnm/asdf/nodenv/Volta).
- Первый запуск: PIN 6–12 цифр с повтором, затем предложение включить сильную биометрию Android.
- Если биометрия включена, запрос появляется автоматически при открытии и возврате в приложение. После отмены можно ввести PIN, повторных автоматических запросов до следующего входа нет. PIN остаётся резервным входом. Смена PIN, отключение биометрии, сброс локальных данных.

## Сборка

Откройте эту папку в Android Studio. Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Gradle Wrapper 8.13 включён. Package/applicationId: `group.prizm.pm2m` (проверьте доступность в Play Console до первой публикации). Минимальная ОС: Android 8.0 / API 26.

```powershell
# Windows; JAVA_HOME должен указывать на JDK 17
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug bundleRelease
```

В Linux/macOS: `sh gradlew testDebugUnitTest lintDebug assembleDebug bundleRelease`.

SDK задаётся через Android Studio, ANDROID_HOME или локальный `local.properties`: `sdk.dir=C\:/Android/sdk`. Инструменты в `.tooling/` нужны только для локальной проверки и не входят в исходный проект/публикацию.

Артефакты: `app/build/outputs/apk/debug/app-debug.apk` и `app/build/outputs/bundle/release/app-release.aab`. Без `keystore.properties` release AAB не подписан и **не готов к загрузке в Play Console**. Для загрузки создайте собственный upload key и заполните `keystore.properties` по примеру. Debug-ключ нельзя использовать для публикации.

```powershell
keytool -genkeypair -keystore pm2m-upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
.\gradlew.bat bundleRelease
```

## Безопасность и ограничения

Хранилище: AES-GCM с отдельным случайным ключом данных. PIN через PBKDF2-HMAC-SHA256 (210000 итераций, случайная соль) оборачивает ключ данных; дополнительный ключ Android Keystore связывает оболочку с устройством. Биометрическая оболочка использует auth-per-use ключ Android Keystore и `BiometricPrompt.CryptoObject`, а не просто флаг успешного диалога. После 5 неверных PIN включается нарастающая задержка. Это не защита от полностью скомпрометированной/рутованной ОС.

При уходе в фон приложение закрывает SSH-сессии, отменяет операции, очищает ссылки на расшифрованные подключения и обнуляет ключ данных. Операция на сервере могла уже завершиться: после возврата проверьте статус перед повтором. Автобэкап и перенос хранилища между устройствами отключены; скриншоты блокируются FLAG_SECURE. PIN/ключи не пишутся в SavedState и логи.

Полученный отпечаток нужно сверить через независимый доверенный канал. Само получение ключа не подтверждает его принадлежность серверу. Нужны bash, PM2 и доступ пользователя к его PM2_HOME. Обнаружение Node.js ничего не устанавливает. Пароли/ключи из веб-проекта не импортируются автоматически.

Приложение не ведёт мониторинг в фоне, не отправляет уведомления и не содержит Telegram. По нажатию «Логи» содержимое показывается только в приложении. Для приватных сетей нужен доступ телефона к этой сети/VPN.

## Проверки перед релизом

Unit-тесты: shell quoting, список PM2 с баннером, валидация действий/путей и профилей. Instrumentation-тесты хранилища: `gradlew connectedDebugAndroidTest` на отдельном тестовом эмуляторе/устройстве. Они сбрасывают данные **debug-приложения**.

Ручной QA: создание PIN/ошибочный PIN/перезапуск/биометрия/смена набора отпечатков/фон/поворот; неправильный SSH-ключ; пароль и OpenSSH key; отключение сети; действия на тестовых процессах; длинные имена и логи; масштаб шрифта 200%; Android 8/15/16 и планшет. Не используйте production-сервисы для проверки удаления.

Материалы публикации и нерешённые поля — в `play/RELEASE-CHECKLIST.md`. Сборка не означает одобрение Google Play. Подпись, аккаунт разработчика, публичный URL политики и отправка на проверку выполняются владельцем.

## Дизайн 1.0.1

Тёмная тема по предоставленному AgentQL Style Reference: поверхности Void/Abyss/Deep Sea, тонкие синие границы, белые основные кнопки, радиусы карточек 12 dp. Шрифты Inter, Figtree и IBM Plex Mono включены локально с OFL-лицензиями. Свечение используется на экране входа. Фоновое обновление означает опрос без вмешательства в интерфейс, пока приложение открыто; при блокировке SSH прекращается.

## Темы 1.0.2

В настройках доступен выбор AgentQL (исходная тема по умолчанию) и Railway (новый приложенный Style Reference). Выбор применяется сразу ко всем экранам и сохраняется локально между запусками. Railway использует IBM Plex Serif, лиловые CTA с радиусом 8 dp, графитовые поверхности и фон ночного неба. Цвет границ взят из полного значения #33323e в описании компонентов: сокращённый #33323 в таблице файла некорректен. Лицензия шрифта включена в assets/licenses.
