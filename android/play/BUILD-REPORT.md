# Проверка сборки — 01.10.2026

Приложение: **pm2m**, разработчик **Prizm.Group**, поддержка **info@filnet.ru**.
Версия 1.0.2 (3), applicationId `group.prizm.pm2m`, min SDK 26, target SDK 36.

## Выполнено

- Для 1.0.1 `testDebugUnitTest`: 7 тестов прошли, 0 ошибок; SSH integration в этом запуске пропущен (fixture не запущен). Добавлены регрессии открытия лога внизу / сохранения позиции и однократного автоматического запроса биометрии. SSH integration успешно выполнялся для 1.0.0; SSH-клиент не менялся.
- `lintDebug`: успешно, ошибок нет. 10 предупреждений о более новых версиях инструментов/зависимостей; версии закреплены в проекте.
- `assembleDebug`, `assembleDebugAndroidTest`, `bundleRelease`: успешно, включая R8 для release.
- Подпись установочного debug APK проверена `apksigner verify`, схема v2.
- `zipalign -c -P 16 4`: debug APK прошёл проверку.
- ELF PT_LOAD для `libandroidx.graphics.path.so` во всех четырёх ABI имеет alignment 16384. Проверка: `node android/scripts/check-elf.mjs` из корня веб-проекта. Финальную доставку из подписанного AAB нужно дополнительно проверить через Play Console.

## Что не проверено

Instrumentation-тесты `VaultTest` скомпилированы, но не выполнены: на компьютере нет драйвера аппаратного ускорения Android Emulator; запуск без ускорения завершился до появления устройства в ADB. Драйверы и настройки ОС не менялись. Для запуска на тестовом устройстве: `gradlew connectedDebugAndroidTest` (тесты сбрасывают данные debug-приложения).

Ручная проверка интерфейса, PIN, биометрии и жизненного цикла на телефоне остаётся обязательной перед публикацией. Настоящие скриншоты, публичный HTTPS URL политики, ключ подписи и тестовый SSH-сервер для проверяющего пока не предоставлены. Публикация в Google Play не выполнялась.

## Изменения 1.0.1

Незаметный опрос процессов без общего busy, автоматическая биометрия при входе, локальные шрифты и тема по приложенному AgentQL reference. stdout/stderr обновляются с интервалом 10 секунд после ответа, без параллельных запросов и очистки предыдущего содержимого. При открытии — конец лога; при чтении старых строк — сохранение позиции. При закрытии диалога и блокировке опрос прекращается.

## Изменения 1.0.2

Выбор AgentQL / Railway в настройках с немедленным применением и сохранением в локальных SharedPreferences. AgentQL остаётся по умолчанию, в том числе для неизвестного значения настройки. Добавлен локальный IBM Plex Serif с лицензией OFL. Проверены компиляция, lintDebug, assembleDebug и bundleRelease. Визуальная проверка переключения и сохранения темы на телефоне пока не выполнена.
