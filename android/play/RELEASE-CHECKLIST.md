# Подготовка публикации pm2m / Prizm.Group

Проект подготовлен для AAB, но публикация не выполнялась. Название разработчика в Play Console должно быть **Prizm.Group**: https://play.google.com/store/apps/developer?id=Prizm.Group.

## До первой загрузки

- Проверить и закрепить applicationId `group.prizm.pm2m`. Его нельзя поменять у опубликованного приложения.
- Почта поддержки/конфиденциальности: **info@filnet.ru**. Указана в приложении, политике и тексте карточки; перенести в поле контактов Play Console.
- Разместить окончательную политику на общедоступном HTTPS URL без входа, геоблокировок и PDF. Указать ссылку в Play Console, проверить соответствие фактическому приложению.
- Создать и сохранить upload key отдельно от репозитория, подключить Play App Signing. Собрать подписанный release AAB; проверить подпись и package/versionCode.
- Пройти Android instrumentation/ручной QA из README; проверить Pre-launch report в Play Console. SSH-ключи, PIN и биометрию обязательно проверить на реальном устройстве.
- Иконка 512×512 PNG и feature graphic 1024×500 подготовлены в `graphics/`. Подготовить настоящие скриншоты приложения; проверить текущие ограничения Play Console. Не выдавать макеты за скриншоты рабочего приложения. FLAG_SECURE мешает скриншотам: снимайте отдельную демонстрационную сборку с вымышленными данными, не отключайте защиту release.
- Заполнить content rating, target audience, app access, ads и Data safety. Не создавать объявления, аккаунты и публикацию автоматически.

## Требования платформы, проверено 30.09.2026

Target SDK 36 используется по требованиям новых приложений/обновлений с 31.08.2026:
https://developer.android.com/google/play/requirements/target-sdk

Собственный код — Java/Kotlin; Compose транзитивно включает `libandroidx.graphics.path.so`. Проверить ELF alignment и packaging всех ABI финального AAB на совместимость с 16-KiB page size; повторять после обновления зависимостей:
https://developer.android.com/guide/practices/page-sizes

Для новых личных аккаунтов может требоваться закрытый тест с 12 участниками не менее 14 последовательных дней; применимость проверяется в вашем аккаунте:
https://support.google.com/googleplay/android-developer/answer/14151465

## Data safety — исходные сведения для анкеты

В приложении нет аналитики, рекламы, crash-reporting SDK, аккаунтов и backend Prizm.Group. Данные хранятся локально, SSH передаёт аутентификационные данные/команды на сервер, который указывает пользователь. Разработчик не получает эти данные. Биометрические шаблоны недоступны приложению. Передача SSH зашифрована, отпечаток сервера проверяется.

Не отмечайте автоматически «никакие данные не собираются»: сначала сопоставьте передачу на пользовательский сервер с актуальными определениями collection/sharing, ephemeral processing и user-initiated transfer в форме. Ответы подтверждает владелец приложения с учётом конечных зависимостей и поведения релиза:
https://support.google.com/googleplay/android-developer/answer/10787469

Удаление аккаунта: отдельного аккаунта приложения нет. Удаление локальных данных доступно через сброс. Удаление процессов PM2 и серверных данных — разные действия.

## App access / инструкция проверяющему

1. Первый запуск: придумайте тестовый PIN 6–12 цифр, повторите; биометрия необязательна.
2. Добавьте **отдельный тестовый Linux SSH-сервер**, указанный издателем в закрытой форме Play Console. Приложение не содержит production-паролей или серверов.
3. Издатель предоставляет адрес/порт, тестового пользователя, пароль/ключ, SHA256 fingerprint и путь PM2; доступ должен сохраняться на период проверки.
4. Тестовый пользователь должен иметь отдельный PM2_HOME и фиктивные процессы, которые можно останавливать/удалять. Не выдавать reviewer root или доступ к production.
5. Проверить список, рестарт тестового процесса, логи, добавление тестового скрипта, повторный вход по PIN.

Доступ к тестовому серверу пока не создан и не заполнен. Это задача владельца перед отправкой на проверку; приложение не считается готовым к review без воспроизводимого доступа.
